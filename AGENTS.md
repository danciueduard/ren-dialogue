# Ren Dialogue for Stay With Me

- This Windows project uses FastAPI, SQLite, and Ollama.
- Ren is the default companion name. Use one model call for each brief spoken reply.
- Read friendship, romance, and gameplay state from Stay With Me. Treat the mailbox as text only.
- Preserve survivor-specific history and back up this fork's SQLite database before schema changes.
- Keep the source engine, supplied Stay With Me mod, and user's backup folder separate.
- Verify Python, the mailbox and Lua hooks. Disclose what still needs testing inside the game.
